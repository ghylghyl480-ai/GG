# 🛠️ Kit PC — pro seu Positivo (Pentium T4500, 4GB, SSD)

Dois arquivos, dois usos. Nenhum apaga seus arquivos pessoais.

## 1. `modo-eficiencia.ps1` — programa em foco voa 🚀

O que você tá usando (jogo, navegador, whatever) ganha prioridade ALTA no processador; todo o resto fica em prioridade BAIXA. Inclui o antivírus do Windows na lista de protegidos (o script original do Gemini esqueceu dele) e avisa se não estiver como administrador.

**Como usar:**
1. Baixa o arquivo (botão **Raw** → salvar como `modo-eficiencia.ps1`)
2. Botão direito nele → **Executar com PowerShell**
3. Pra parar: fecha a janela

**Dica:** pra valer 100%, abre o PowerShell como Administrador (menu Iniciar → digita `powershell` → botão direito → Executar como administrador) e arrasta o arquivo pra dentro da janela preta.

## 2. `limpeza.bat` — tira o lixo do Windows 🧹

Apaga temporários do usuário, temporários do Windows, cache de update e cache de DNS. Nada de arquivos pessoais.

**Como usar:**
1. Baixa o arquivo (botão **Raw** → salvar como `limpeza.bat`)
2. **Botão direito → Executar como administrador** (ele mesmo exige isso)
3. Espera acabar e reinicia o PC

## Combo completo pro notebook voar

1. Este kit (os 2 arquivos acima)
2. Tirar programas do início do Windows: `Ctrl + Shift + Esc` → aba **Inicializar** → desativa o que não precisa
3. Efeitos visuais: menu Iniciar → digita `ajustar` → "Ajustar a aparência e o desempenho" → **Ajustar para obter um melhor desempenho**
4. Arquivos pesados (filmes, ISOs, backups) no HD de 300GB; sistema e programas no SSD
